👻 虚拟离屏隐形运行机制

微信主窗口通过 Win32 API 被置入操作系统负坐标区域（X: -3000, Y: -3000）。不同于系统最小化（ShowWindow SW_MINIMIZE 会挂起 DirectComposition 渲染），负坐标离屏状态下 Windows 渲染子系统依然为窗口分配全尺寸 FrameBuffer，使 DWM/PrintWindow 能够稳定抓取 100% 真实渲染画面。

SetWindowPos(hwnd, 0, -3000, -3000, w, h, SWP_SHOWWINDOW)

⚡ 20ms 动态像素哨兵算法

为解决传统 OCR 机器人持续死循环高频识别导致 CPU 满载发热与风扇狂转问题，引入切片 MD5 快速哈希与红像素快筛。每 0.8s 轮询周期仅耗费 20ms 提取侧边栏与聊天区像素并计算哈希，画面无变化直接放行，OCR 推理频率降低 90% 以上。

hashlib.md5(chat_patch.tobytes()).hexdigest()

🛡️ 群聊与白名单物理级防火墙

在消息分发的最前端设立物理级熔断规则：正则严格匹配末尾括号人数（如 交流群(25) 或 交流群 (25)）以及 20+ 类群关键词。白名单匹配采用剥离红点变体、全等匹配、越配防御（拒绝后随普通字符≤3的名字），杜绝任何串发社死可能。

re.search(r'[\(（]\d+[\)）]$', name_segment)

✅ 三态闭环验收与熔断状态机

每次发送完成后，不盲目假设成功，而是等待 0.35s 微信动画沉降，二次抓取画面并分析输入框上方 80px 窄带与 220px 全局气泡区的绿底像素增量。若明确增量返回 True；若离屏抓取黑屏返回 UNCERTAIN 并安全熔断防复读；连续脱靶 2 次锁定指纹彻底终止。
